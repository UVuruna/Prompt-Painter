# Certificate Generator

**Script:** [Certificate Generator (script)](../create_cert.py)

## Purpose

One-time script that creates the self-signed code-signing certificate
`build.py` later uses to sign the exe and installer. Run manually once
per project (`python setup/create_cert.py`); re-run only if the
certificate expires or is corrupted — it refuses to overwrite an
existing `.pfx`, so a stale certificate must be deleted by hand first.

## Connections

### Uses
- `app_info.json` (this folder) — `APP_NAME`, used to name the output `{APP_NAME}.pfx`
- `cert/password.txt` (gitignored) — must already exist; the password is chosen by the owner ahead of time, not generated by this script
- PowerShell's `New-SelfSignedCertificate` / `Export-PfxCertificate` cmdlets — create a 5-year `CodeSigningCert` (`CN=UVuruna`) in the CurrentUser\My store and export it to the `.pfx`

### Used by
- [Build Orchestrator](build.md) — `sign_file` reads the `.pfx` this script produces (not imported; expected to have been run first). The owner runs this script manually, standalone.

## Functions

- `_load_password()` — reads and strips `cert/password.txt`; raises `FileNotFoundError` with setup instructions if the file is missing. Called at module level (`PFX_PASSWORD = _load_password()`), so the script fails fast before touching PowerShell at all if no password file exists yet
- `create_certificate()` — if `cert/{APP_NAME}.pfx` already exists, prints a message and returns without touching it; otherwise creates `cert/` and runs a PowerShell script that generates the self-signed certificate and exports it to that path protected by `PFX_PASSWORD`; prints the certificate thumbprint and a reminder that `cert/` is gitignored and must never be committed
